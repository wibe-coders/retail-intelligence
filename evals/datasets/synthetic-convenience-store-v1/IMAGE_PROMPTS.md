# Synthetic product image prompts

The built-in image-generation tool produced four 3 × 2 catalog sheets. Each sheet was cropped on
its exact 512-pixel grid into six final product images. No source-store pixels were used.

## Common prompt

```text
Use case: product-mockup
Asset type: synthetic convenience-store inventory catalog sprite sheet
Primary request: Create exactly six distinct fictional products arranged in a strict 3-column by
2-row grid.
Scene/backdrop: six equal pure-white rectangular cells with generous margins and faint light-gray
divider lines.
Style/medium: consistent photorealistic e-commerce product photography.
Composition/framing: one unopened item centered and fully visible in each equal cell; identical
visual scale; front-facing; no object crosses a divider; no perspective sheet tilt.
Lighting/mood: soft neutral studio lighting with a small contained contact shadow inside each cell.
Text: no readable words, letters, prices, numbers, barcodes, trademarks, or brand names; icons and
abstract color bands only.
Constraints: exactly six products, strict grid alignment, clean silhouettes, fictional unbranded
packaging, no people, no watermark.
Avoid: extra products, duplicate products, hands, shelves, scenery, cropped objects, overlapping
objects, text-like gibberish.
```
